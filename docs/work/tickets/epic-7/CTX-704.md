# Ticket: CTX-704 Module Connectors For Finance, Second Brain, And Homelab

## Context

The adapter needs explicit connectors for each module so the orchestrator can call old module services consistently.

## Scope

- Finance connector for read/report and validated write-capable APIs.
- Second Brain connector for capture inbox and RAG search.
- Homelab connector for sync/search/link validation read-only tools.
- Shared connector result model with citations/warnings/errors.

## Out of Scope

- New Finance business rules.
- Direct Vault writes.
- Homelab repo edits or operational command execution.

## Acceptance Criteria

- [ ] Finance connector uses existing Finance service/API contracts.
- [ ] Second Brain connector keeps capture buffer excluded from RAG.
- [ ] Homelab connector is read-only and redaction-aware.
- [ ] Connectors use the same shared PostgreSQL DB with module-separated tables.
- [ ] Tests cover representative tool calls for all three modules.

## Small Task Exemption

- Small task exemption: no

## Test Expectations

- Integration tests using local PostgreSQL `cortex`.
