# Ticket: CTX-705 Second Brain And Homelab Module Connectors

## Context

CTX-700 through CTX-704 created the transport-neutral orchestration contracts, conversation/confirmation persistence, tool registry, ReAct loop, and Telegram transport. The next unblocker is a real connector layer that lets ReAct tool calls execute existing module services without duplicating domain logic.

The earlier CTX-705 draft described a Policy/Audit gRPC bridge. That work remains necessary for production Finance writes and audit-backed policy decisions, but it is split out of this slice because it requires Go service exposure and protobuf work. This ticket implements the Python module connectors that can be verified independently against existing Second Brain and Homelab services.

## Scope

- Implement `SecondBrainConnector` as an orchestrator `ModuleConnector`.
  - `CreateCapture` calls `SecondBrainService.create_capture`.
  - `ListCaptures` calls `SecondBrainService.list_captures`.
  - `GetSyncStatus` calls `SecondBrainService.get_sync_status`.
  - `SearchKnowledge` calls `SecondBrainService.search_knowledge`.
- Implement `HomelabConnector` as an orchestrator `ModuleConnector`.
  - `GetSyncStatus` calls `HomelabService.get_sync_status`.
  - `SearchKnowledge` calls `HomelabService.search_knowledge`.
  - `ValidateLinks` calls `HomelabService.validate_markdown_links`.
  - `SyncRepository` wraps the authorized mirror/index sync path only.
- Normalize connector outputs into `ToolObservation` with safe user messages, structured data, warnings, and citations.
- Update tool registry definitions for Second Brain/Homelab targets so connector validation can catch drift.
- Add focused unit/integration-style tests using fake embeddings and SQLite repositories.

## Out Of Scope

- Finance connector implementation.
- Policy/Audit gRPC bridge to Go services.
- New database schema or migrations.
- New prompt/ReAct state-machine behavior.
- Direct writes to Obsidian Vault or Homelab repo.

## Acceptance Criteria

- [x] `SecondBrainConnector` registers with `ConnectorRegistry` and supports all registered Second Brain targets.
- [x] Second Brain capture preserves provided tags, writes only to the capture inbox DB, and reports `vault_write=false`.
- [x] Second Brain search returns normalized citations with vault path, indexed revision, chunk id, and snippets.
- [x] `HomelabConnector` registers with `ConnectorRegistry` and supports registered Homelab targets.
- [x] Homelab search returns redacted snippets with `file_path @ commit_sha` citations.
- [x] Homelab link validation maps service results into a `ToolObservation`.
- [x] Homelab repo-path tools reject unconfigured or non-allowlisted local paths.
- [x] Connector tests verify registry validation, mapping, citations, and source-of-truth boundaries.
