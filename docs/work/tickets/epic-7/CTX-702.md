# Ticket: CTX-702 Tool Registry And JSON Schema Contracts

## Context

The LLM runtime needs a strict registry describing available tools without leaking domain implementation details into prompts.

## Scope

- Create a tool registry with name, description, JSON schema, required capability, confirmation policy, and output contract.
- Register Finance, Second Brain, Homelab, and system tools in groups.
- Validate tool input schemas before adapter execution.
- Provide a provider-neutral representation convertible to Google/OpenAI tool formats.

## Out of Scope

- Executing tool calls.
- Adding new domain APIs.

## Acceptance Criteria

- [x] Schema structure for `list_tools` mapping and Google/OpenAI JSON bindings is defined.
- [x] Schema enforces parameters, required arguments, and types.
- [x] Registry can list tools by capability/module.
- [x] Tools are categorized and contain explicit mapping to underlying APIs.
- [x] `FakeLLMProvider` is updated to accept the new tool definitions.
- [x] Homelab tools are read-only.
- [x] Tests cover schema validation, capability metadata, and provider format conversion.

## Small Task Exemption

- Small task exemption: no

## Test Expectations

- Unit tests for schema validation and registry filtering.
