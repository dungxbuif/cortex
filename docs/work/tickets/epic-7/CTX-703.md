# Ticket: CTX-703 LLM/ReAct Runtime Loop

## Context

To achieve flexible, multi-step problem solving, the orchestrator needs an explicit, asynchronous ReAct state machine loop instead of a static router. This state machine manages tool-calling iterations, missing argument clarification, confirmation checks, and policy denials.

## Scope

- Implement the ReAct loop control logic in Python as an async state machine:
  - States: `LoadConversation`, `CheckPendingConfirmation`, `BuildContext`, `CallLLM`, `ValidateToolArguments`, `CheckPolicy`, `ExecuteTool`, `ObserveResult`, `Synthesize`, `Clarify`, `Confirm`, `Deny`, `Fallback`, `SaveConversation`.
- Enforce strict runtime execution boundaries and guards:
  - Maximum ReAct iterations limit (e.g., 5 loops) to prevent infinite LLM tool-calling loops.
  - Request execution timeouts.
  - Failure handler to gracefully fallback to safe messages when the provider fails, times out, or cannot reach a valid terminal state.
- Wire system and developer prompts dynamically into the context builder.
- Write unit tests using a mock LLM provider to verify control-flow transitions.

## Out of Scope

- Implementing specific connector adapters.
- Interacting with real gRPC services (policy/audit/finance) - these are mocked for testing the state machine.
- Real Google Gemini client calls (tested in smoke tests).

## Acceptance Criteria

- [x] Orchestrator supports standard ReAct loop: Observe, Think, Act, Validate.
- [x] Multi-step execution uses the `FakeLLMProvider` and tests handle >= 3 execution hops.
- [x] Hard cap (`MAX_TURNS` = 5) forces gracefully fallback.
- [x] ValidateToolArguments catches missing/invalid arguments and clarifies with LLM without crashing.
- [x] CheckPolicy and Confirmation behaviors correctly suspend the execution loop.
- [x] Loop resumption from Webhook/Telegram `Yes` is tested.
- [x] Async timeouts are respected and provider exceptions trigger graceful degradation.
- [x] Comprehensive unit tests cover happy-path tool execution, provider exceptions, max turn limit, and invalid tool arg feedback.
