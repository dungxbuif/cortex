# Ticket: CTX-703 Tool Adapter Execution Layer

## Context

Tool calls from the LLM must be mapped into existing domain APIs without duplicating business logic in the orchestrator.

## Scope

- Implement tool adapter interface: validate, authorize, execute, normalize result.
- Map LLM arguments to service DTOs or existing service method calls.
- Normalize errors into validation, not found, denied, needs confirmation, and provider/runtime errors.
- Add idempotency/request id handling for write-capable tools where applicable.

## Out of Scope

- New domain feature behavior.
- Persistence schema changes except minimal adapter metadata if approved later.

## Acceptance Criteria

- [ ] Adapter executes read-only tools safely.
- [ ] Adapter blocks invalid tool arguments before domain execution.
- [ ] Adapter never writes Homelab or Obsidian Vault.
- [ ] Adapter returns structured observations for response synthesis.
- [ ] Tests cover success, invalid input, denied operation, and domain error mapping.

## Small Task Exemption

- Small task exemption: no

## Test Expectations

- Unit tests with fake services.
- Integration tests against local PostgreSQL/pgvector for real module calls.
