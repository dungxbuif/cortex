# Ticket: CTX-707 Second Brain Connector (Retired)

> [!NOTE]
> This ticket is **retired**. Its scope was consolidated into [CTX-705](CTX-705.md) (Second Brain And Homelab Module Connectors) and implemented/verified there.

## Context

Second Brain knowledge and inbox captures must be accessible to the orchestrator. The orchestrator needs a module connector wrapping `SecondBrainService` that enforces the vault writing and RAG isolation constraints.

## Scope

- Implement `SecondBrainConnector` implementing `ModuleConnector` in Python.
- Register the following tools in `ToolRegistry`:
  - `secondbrain_capture_note`: Captures user thoughts.
  - `secondbrain_list_captures`: Queries captured ideas.
  - `secondbrain_get_sync_status`: Gets index state.
  - `secondbrain_search_knowledge`: Searches Obsidian Markdown vault documents.
- Connect methods to call `SecondBrainService` in-process.
- Enforce strict repository rules:
  - Writes must go ONLY to the capture inbox database table, never directly to the Obsidian Vault files.
  - RAG search must ONLY query indexed vault snapshot/mirror documents, never capture inbox buffer tables.
- Normalize search outcomes into presentation-ready citation metadata, including:
  - Source vault paths (e.g. `vault_path @ indexed_at/source_revision`).
  - Snippets and title references.
- Include database-bound capture notifications stating that file writing did not occur (`vault_write=false`).

## Out of Scope

- Implementing the LLM ReAct loop.
- Implementing MinIO/S3 sync hooks (already exist).

## Acceptance Criteria

- [ ] `SecondBrainConnector` is registered in `ConnectorRegistry` and matches registered schemas.
- [ ] Note captures execute successfully and write ONLY to capture DB tables.
- [ ] RAG search queries only vector indexes of mirror documents, excluding inbox buffers.
- [ ] Search results translate to normalized citations including vault path and revision info.
- [ ] Integration tests verify tool mapping and service execution.

## Small Task Exemption

- Small task exemption: no

## Test Expectations

- Integration tests calling `SecondBrainConnector` to verify capture logs, RAG query behavior, citation generation, and security boundaries.
