# Ticket: CTX-706 Tool Adapter Executor

## Context

The orchestrator needs a secure executor middleware that sits between the LLM tool-calling output and connector dispatch. It must guarantee that no tool executes without first passing schema validation, policy authorization, confirmation checks, and audit logging.

## Scope

- Implement the `ToolAdapterExecutor` in Python to coordinate:
  - Argument validation: checks arguments using registry schemas.
  - Policy checks: queries `PolicyGrpcClient` for authorization status.
  - Confirmation logic: if policy indicates `require_confirmation`, persists details to `pending_confirmations` via `ConversationManager` and yields a confirmation response.
  - Dispatching: locates the matching module connector in `ConnectorRegistry` and delegates target API execution.
  - Audit logging: emits post-execution details (success, duration, error) to `AuditGrpcClient`.
  - Error mapping: intercepts connector exceptions and normalizes them into structured `ToolObservation` messages (e.g. mapping gRPC status codes to observation statuses).
- Write unit tests covering validation blocks, policy redirects, and confirmation gates.

## Out of Scope

- Implementing the domain connectors (Second Brain, Homelab, Finance).

## Acceptance Criteria

- [ ] `ToolAdapterExecutor` rejects execution when tool arguments fail schema validation.
- [ ] Executor halts and records confirmation data when policy requires approval.
- [ ] Executor bypasses actual connector call when policy returns `Deny`.
- [ ] Successful tool executions yield normalized `success` observations and write audit events.
- [ ] Connector failures (timeouts, network, domain validation) map correctly to standard observation statuses.
- [ ] Unit tests cover all middleware check branches (allow, deny, confirm, error, validate).

## Small Task Exemption

- Small task exemption: no

## Test Expectations

- Mock-based unit tests for executor flow routing, validation errors, confirmation triggers, policy rejections, and exception normalization.
