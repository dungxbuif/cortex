# Ticket: CTX-709 Eval Replay And E2E Chat

## Context

We need to prove that the orchestrator behaves correctly, securely, and stably before finalizing the Epic. This ticket covers final evaluation replays, opt-in provider integration tests, and end-to-end (E2E) manual verification.

## Scope

- Setup an evaluation dataset of baseline prompts and expected trajectories:
  - Text-only reasoning.
  - Second Brain capture.
  - Second Brain search with citation.
  - Homelab search with citation.
  - Homelab write denial.
  - Finance read/report query.
  - Finance write denial query (since write is unsupported).
  - Provider failure fallback.
  - Offline gRPC service fallback (Graceful degradation).
  - Stale index warning injection.
  - Missing argument clarification.
- Implement an evaluation runner in Python that executes these scenarios using mock provider replays, verifying chosen tool steps, arguments, and terminal states.
- Implement opt-in provider smoke tests:
  - Run the orchestrator using a real configured Gemini API provider when credentials and opt-in env flags are set.
- Conduct final E2E manual/UAT validation:
  - Verify access allowlist, HTML rendering, message chunking, and typing indicator flows in Telegram.
- Update `docs/work/VALIDATION_MATRIX.md` with complete evidence.

## Out of Scope

- Automated UI testing using real Telegram clients.

## Acceptance Criteria

- [ ] Replay test suite verifies happy paths, clarifies, confirmations, denials, and fallbacks.
- [ ] Opt-in smoke tests pass cleanly with Google provider.
- [ ] Telegram UAT verifies formatting, allowlists, chunking, and typing indicator.
- [ ] `docs/work/VALIDATION_MATRIX.md` is updated.
- [ ] Phase 7 status updated to `done`.
