# Ticket: CTX-708 Homelab Connector (Retired)

> [!NOTE]
> This ticket is **retired**. Its scope was consolidated into [CTX-705](CTX-705.md) (Second Brain And Homelab Module Connectors) and implemented/verified there.

## Context

The orchestrator needs a secure read-only bridge to query the Homelab infrastructure documents. To prevent accidents, any tool call trying to write, patch, commit, push, or execute commands in the repository must be rejected.

## Scope

- Implement `HomelabConnector` implementing `ModuleConnector` in Python.
- Register the following tools in `ToolRegistry`:
  - `homelab_get_sync_status`: Reads repository snapshot status.
  - `homelab_search_knowledge`: Searches redacted and indexed repository docs.
  - `homelab_validate_links`: Validates system markdown linkages.
  - `homelab_sync_repository`: Syncs the repo mirror (authorized sync path only, not user operational commands).
- Call `HomelabService` in-process.
- Enforce strict read-only boundary:
  - Reject attempts to write files, construct commits, or run shell scripts before tool dispatch.
- Normalize search outcomes into presentation-ready citation metadata:
  - Output paths formatted as `file_path @ commit_sha`.
  - Redact sensitive keys, credentials, or network details before returning results.

## Out of Scope

- Modifying files, creating commits/patches, or running operational shell commands.

## Acceptance Criteria

- [ ] `HomelabConnector` maps target APIs correctly to `HomelabService` methods.
- [ ] No write-capable tools are exposed or permitted by the connector.
- [ ] Citations correctly format paths and commit SHAs without leaking secrets.
- [ ] Integration tests verify search, status, and link validation operations.

## Small Task Exemption

- Small task exemption: no

## Test Expectations

- Integration tests calling `HomelabConnector` to verify tool checks, search citations, and verify secret/credential redaction.
