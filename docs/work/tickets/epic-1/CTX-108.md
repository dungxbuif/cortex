# CTX-108: Net Worth API

## Problem
Domain API - Net Worth (Tính tổng Cash + Assets - Debts).

## Acceptance
- [ ] AC-CTX-108-001: Net worth combines included cash wallets, current asset values, and debts/credit balances.
- [ ] AC-CTX-108-002: Current asset values use latest usable asset price, not historical buy price.
- [ ] AC-CTX-108-003: Net worth output includes cash, gold, stocks/funds, saving deposits, crypto when present, debts, total net worth, realized gain/loss, and unrealized gain/loss.
- [ ] AC-CTX-108-004: Gold valuation uses sell price when available; stocks/funds/crypto use close, last, or manual price depending on source.
- [ ] AC-CTX-108-005: Saving deposits are valued as assets when they have term/interest behavior; liquid bank accounts remain wallets.
- [ ] AC-CTX-108-006: Net worth v1 subtracts credit wallet balances and explicitly reports whether full debt/loan tables are not yet included.
- [ ] AC-CTX-108-007: Unit tests cover stale/missing price behavior, deterministic price priority, saving deposit classification, and valuation by asset class.
