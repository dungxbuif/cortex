# CTX-106: Asset Transaction API

## Problem
Domain API - Asset Transaction (Mua/Bán tài sản & xử lý cash movement).

## Acceptance
- [ ] AC-CTX-106-001: Asset transaction API records buy, sell, transfer in/out, dividend, stock dividend, split, and manual adjustment types.
- [ ] AC-CTX-106-002: Buy/sell/dividend operations can link to cash wallet movement without counting investment buys as living expenses.
- [ ] AC-CTX-106-003: Asset transactions persist quantity, unit price, gross amount, fee, tax, net amount, occurred date, and linked cash transaction id.
- [ ] AC-CTX-106-004: Holdings are updated with quantity, weighted-average cost, total remaining cost, realized gain, and current valuation fields.
- [ ] AC-CTX-106-005: Asset price history records market prices over time without overwriting historical prices.
- [ ] AC-CTX-106-006: Holding rebuild from historical asset transactions produces the same result as incremental updates.
- [ ] AC-CTX-106-007: Unit tests cover holdings, weighted-average cost, realized gain/loss, price history, rebuild behavior, and wallet cash movement.
