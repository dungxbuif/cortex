# CTX-109: Debt & Loan Tracking API

## Problem

Domain API - Track money I owe other people and money other people owe me, including payments/collections and remaining balance.

## Acceptance

- [ ] AC-CTX-109-001: Debt/loan record can be created with direction, counterparty, principal amount, currency, due date, note, and status.
- [ ] AC-CTX-109-002: Direction supports `i_owe` and `owed_to_me`.
- [ ] AC-CTX-109-003: Payment against `i_owe` creates or links a cash transaction that reduces wallet balance and reduces remaining debt.
- [ ] AC-CTX-109-004: Collection against `owed_to_me` creates or links a cash transaction that increases wallet balance and reduces remaining receivable.
- [ ] AC-CTX-109-005: Debt/loan status can move through active, partially settled, settled, forgiven, and archived.
- [ ] AC-CTX-109-006: Net worth subtracts active `i_owe` remaining balance and adds active `owed_to_me` remaining balance.
- [ ] AC-CTX-109-007: Unit tests cover direction, remaining balance, overpayment prevention, linked cash movement, and net-worth impact.
