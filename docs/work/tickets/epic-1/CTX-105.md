# CTX-105: Asset Master API

## Problem
Domain API - Asset Master (Quản lý danh mục tài sản đầu tư: Vàng, Cổ phiếu).

## Acceptance
- [ ] AC-CTX-105-001: Asset master can be created with asset type, symbol, name, currency, unit, price source, and active state.
- [ ] AC-CTX-105-002: Asset master can be updated without rewriting historical asset transactions.
- [ ] AC-CTX-105-003: Asset master can be deactivated and excluded from new asset transactions while preserving history.
- [ ] AC-CTX-105-004: Supported asset types include gold, stock, fund, crypto, saving deposit, cash equivalent, and other.
- [ ] AC-CTX-105-005: Unit tests cover asset type validation, unit handling, duplicate symbol constraints, and deactivation behavior.
