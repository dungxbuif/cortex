## Context

CTX-403 stabilized imports, CTX-404 isolated provider access behind `Embedder`, and CTX-405 split models/repositories by domain. CTX-406 now makes service files smaller and more testable by extracting pure domain helpers and separating chunking from embedding where practical.

## Scope

- `secondbrain/markdown.py` returns raw chunk content without embedding.
- `secondbrain/service.py` owns embedding orchestration using the injected `Embedder`.
- Extract Homelab redaction into `homelab/redaction.py`.
- Extract Homelab Markdown link validation into `homelab/link_validator.py`.
- Extract Homelab markdown chunking into a testable helper if it reduces service size and keeps behavior stable.
- `homelab/service.py` owns use-case orchestration and delegates pure helpers.
- Remove default construction of provider clients from domain services except through the existing `_default_embedder()` composition helper.

## Out of Scope

- Repository split; completed by CTX-405.
- Python gRPC server; belongs to CTX-407.
- Go gateway; belongs to CTX-408.
- New DB schema or migrations.
