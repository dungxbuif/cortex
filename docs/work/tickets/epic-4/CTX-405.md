# Ticket: CTX-405 Domain Models and Repository Split

## Status

- ID: CTX-405
- Status: verified
- Type: feature
- Priority: High
- Phase: PHASE-4-restructuring
- Owner: shared

## Context

CTX-403 stabilized the `ai_service.*` import baseline. CTX-404 isolated AI provider access behind the `Embedder` port. CTX-405 now splits the current `core/repository.py` and shared model file so Second Brain and Homelab persistence contracts can evolve independently.

## Scope

- Move Second Brain dataclasses into `secondbrain/models.py`.
- Move Homelab dataclasses into `homelab/models.py`.
- Keep shared status/enums/time helpers in `core/models.py`.
- Add `SecondBrainRepository` and `HomelabRepository` protocols in `core/ports.py`.
- Create `secondbrain/repository.py` for Second Brain query methods.
- Create `homelab/repository.py` for Homelab query methods.
- Keep only shared SQL helpers/base psql runner in `core/repository.py`.

## Out of Scope

- Transport changes.
- Go gateway.
- Protobuf generation.
- New DB schema or migrations unless a failing repository contract proves a required fix.

- [x] Existing Second Brain tests pass against PostgreSQL.
