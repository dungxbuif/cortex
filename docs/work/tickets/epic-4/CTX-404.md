## Context

CTX-403 repaired the renamed `ai_service.*` package baseline. CTX-404 now removes direct provider coupling from the service layer by introducing explicit AI ports and provider adapters. This prepares CTX-406 domain cleanup and CTX-407 gRPC handlers to use fake or real embedding providers consistently.

## Scope

- Add `ai_service/core/ports.py` with `Embedder` protocol.
- Move provider code from `core/google_ai.py` to `providers/google_ai.py`.
- Add `providers/embedding.py` with `GoogleEmbedder`.
- Add deterministic fake embedder utilities for non-smoke tests.
- Rename `SecondBrainSettings` to `AIServiceSettings` while keeping backward-compatible alias if needed.
- Add `AI_SERVICE_*` env variable reads with fallback to existing `SECOND_BRAIN_*` values.

## Out of Scope

- Repository split; belongs to CTX-405.
- Domain chunking/service cleanup; belongs to CTX-406 unless required to keep imports green.
- Python gRPC server; belongs to CTX-407.
- Go gateway; belongs to CTX-408.
- Finance REST routes.
