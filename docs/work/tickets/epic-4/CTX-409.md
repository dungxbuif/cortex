## Context

CTX-407 and CTX-408 verified Python gRPC and Go gateway code separately. CTX-409 adds a repeatable local harness so both services can be started together against the local `cortex` dev database and checked through the Go gateway.

- Allow Python gRPC server port to be configured by environment.
- Add a local script to start Python gRPC and Go gateway together.
